# Sorteador de Números — Ceak Conchal

Aplicação web simples e elegante para realizar sorteios de números aleatórios.

## Funcionalidades

- Escolha a quantidade de números a sortear.
- Defina o intervalo mínimo e máximo dos números.
- Sorteio sem repetição dentro do intervalo escolhido.
- Histórico de sorteios salvos no navegador (localStorage).
- Animação opcional durante o sorteio.
- Design responsivo para desktop e mobile.

## Tecnologias

- [TanStack Start](https://tanstack.com/start)
- [React](https://react.dev)
- [TypeScript](https://www.typescriptlang.org)
- [Tailwind CSS](https://tailwindcss.com)
- [shadcn/ui](https://ui.shadcn.com)

## Desenvolvimento local

Você precisa do Node.js instalado. Recomendamos usar o [nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <url-do-repositorio>
cd <nome-do-repositorio>
npm i
npm run dev
```

A aplicação estará disponível em `http://localhost:8080`.

## Build de produção

```sh
npm run build
```
